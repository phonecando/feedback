# PhoneCanDo feedback

The front desk for [PhoneCanDo](https://phonecando.app), the app that runs AI
agents on your Android phone and lets them use it. No code lives here, just
your bugs, wishes and questions, where everyone can find the answers.

## Pick a door

- **Something broke?** [Report a bug](https://github.com/phonecando/feedback/issues/new?template=bug-report.yml).
  Search first: someone may have beaten you to it, and a 👍 on theirs helps
  us more than a twin.
- **An agent you want built in?** [Ask for an agent](https://github.com/phonecando/feedback/issues/new?template=agent-request.yml).
- **An idea?** [Pitch it](https://github.com/phonecando/feedback/issues/new?template=idea.yml).
- **A question, or just showing off what your agents did?**
  [Discussions](https://github.com/phonecando/feedback/discussions).
- **A security hole?** Never in public: report it
  [privately](https://github.com/phonecando/feedback/security/advisories/new)
  ([`SECURITY.md`](SECURITY.md)).
- **Help with your install or your data?** support@phonecando.app.

Don't paste API keys, tokens, passwords or anything off your screen you
wouldn't post on a billboard. Everything here is public.

## Where everything else is

- [phonecando/distribution](https://github.com/phonecando/distribution): the
  app's releases, and how to check them.
- [phonecando/phone-control](https://github.com/phonecando/phone-control): the
  open part, the code that lets agents see and touch your phone. Issues about
  that code go there.
- The rest of the app is closed source, so this repo is how you reach us
  about it.
