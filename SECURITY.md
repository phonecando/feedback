# Security

Found a way to make PhoneCanDo do something it shouldn't? Thank you. Please
tell us privately, never in a public issue or discussion:

- **Security → Report a vulnerability** on this repo
  (<https://github.com/phonecando/feedback/security/advisories/new>), for
  anything in the app.
- Holes in phone control's own code can go to
  [phonecando/phone-control](https://github.com/phonecando/phone-control/security/advisories/new),
  and anything about how releases are built or signed to
  [phonecando/distribution](https://github.com/phonecando/distribution/security/advisories/new).
  Not sure which? Use this one; we'll move it.
- Can't use GitHub? Write to hi@phonecando.app with "Security" in the
  subject.

Tell us the app version and channel (Settings → About: full, lite or play),
your phone and Android version, what you found and the steps to show it.
Please test only on your own phone and accounts.

We reply within 7 days, keep you posted while we fix it, and credit you when
we publish the advisory, unless you'd rather we didn't. We fix the latest
release, so update first if you can.
